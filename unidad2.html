Conceptos básicos

Documento, capas, guardar y deshacer.

Tema 1 · Conceptos básicos

Photoshop en el trabajo real

  • Photoshop es el editor de imágenes de mapa de bits más usado en diseño: edita píxeles.
  • Para la web se usa para banners, fotos de productos, imágenes para redes sociales, botones y maquetas de páginas.
  • Trabaja con capas: cada elemento se edita sin dañar los demás.
  • El archivo de trabajo es PSD; para publicar se exporta en JPEG, PNG o WebP.
  • En el salón usamos Photoshop CS6; las versiones CC funcionan casi igual.

Tema 1 · Conceptos básicos

Lo esencial antes de empezar

Editor de mapa de bits

Photoshop edita píxeles: fotos, banners, retoques y composiciones para la web e impresión.

Documento nuevo

File › New (Ctrl + N): ancho y alto, resolución, modo de color y contenido del fondo.

Abrir y colocar

Ctrl + O abre una imagen. File › Place la coloca como capa dentro de otro documento.

Capas

Hojas transparentes apiladas: cada elemento en su capa se edita sin tocar los demás (F7).

Guardar

Ctrl + S guarda; Shift + Ctrl + S guarda como. El archivo de trabajo es PSD.

Deshacer

En CS6, Ctrl + Z alterna el último paso y Alt + Ctrl + Z retrocede varios. Panel History.

Espacio de trabajo

Dónde está cada cosa en Photoshop CS6.

Tema 2 · Espacio de trabajo

Las seis zonas del espacio de trabajo

Barra de menús

File, Edit, Image, Layer, Type, Select, Filter, 3D, View, Window y Help.

Barra de opciones

Debajo del menú. Cambia según la herramienta que tengas activa.

Barra de herramientas

A la izquierda. Cada herramienta tiene una tecla; un triángulo indica herramientas agrupadas.

Ventana del documento

En pestañas: nombre, zoom y modo de color. Abajo, la barra de estado.

Paneles

A la derecha: Layers (F7), Color (F6), Swatches, Adjustments, History… En el menú Window.

Espacios de trabajo

Window › Workspace: Essentials, Photography, Painting… Reset Essentials devuelve el orden original.

Reglas, cuadrículas y guías

Tema 3 · Reglas, cuadrículas y guías

Medir y alinear con precisión

  • Reglas: Ctrl + R. Clic derecho sobre la regla para cambiar la unidad (píxeles para la web).
  • Guías: arrastra desde la regla; o View › New Guide con la posición exacta. Con la herramienta Move (V) se mueven.
  • Mostrar u ocultar guías: Ctrl + ; · Bloquearlas: Alt + Ctrl + ; · Borrarlas: View › Clear Guides.
  • Cuadrícula: Ctrl + ' (apóstrofo). Su tamaño se cambia en Preferences › Guides, Grid & Slices.
  • Ajustar (Snap): Shift + Ctrl + ; hace que los objetos se peguen a guías y bordes.
  • Smart Guides (View › Show) aparecen solas al mover capas y muestran la alineación.

Tema 4 · Vista o imagen

Cambiar la vista no es cambiar la imagen

Cambia solo la vista

  • Zoom (Z), Ctrl + / Ctrl −, Ctrl + 0, Ctrl + 1.
  • Mano (H o barra espaciadora).
  • Rotate View (R).
  • Modos de pantalla (F).
  • El archivo no cambia.

Cambia la imagen

  • Image › Image Size (Alt + Ctrl + I).
  • Image › Canvas Size (Alt + Ctrl + C).
  • Image › Image Rotation.
  • Crop Tool (C).
  • Cambian los píxeles del archivo.
