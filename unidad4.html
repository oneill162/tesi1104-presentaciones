01

Ventana del documento

La pestaña y la barra de estado dicen casi todo.

Tema 1 · Ventana del documento

Qué te dice la ventana del documento

  • Pestaña: nombre, zoom y, entre paréntesis, modo de color y bits por canal: «foto.psd @ 33.3 % (RGB/8)».
  • Reglas (Ctrl + R): clic derecho para cambiar la unidad.
  • Barra de estado: zoom y peso «Doc: 17.2M/17.2M» (sin capas / con capas).
  • El triángulo de la barra cambia a Document Dimensions, Profile y otros datos.
  • Clic sostenido sobre la barra de estado muestra ancho, alto, canales y resolución.

Ejemplo de lectura

A_foto.psd @ 33.3% (RGB/8)

33.33%   Doc: 17.2M/17.2M

→ 3000 × 2000 px
→ RGB, 8 bits por canal
→ 17.2 MB sin comprimir

02

Soporte

¿Dónde se va a ver la imagen?

Tema 2 · Soporte

Pantalla o papel: el soporte decide los parámetros

Pantalla (web, redes, video)

  • Se piensa en píxeles.
  • Modo RGB, perfil sRGB.
  • Resolución por costumbre 72 ppi (no cambia cómo se ve).
  • Preset Web en File › New.
  • Peso pequeño para que cargue rápido.

Papel (afiches, volantes)

  • Se piensa en pulgadas o centímetros.
  • Modo CMYK (lo confirma la imprenta).
  • 300 ppi para calidad.
  • Preset International Paper o U.S. Paper.
  • Margen de corte (sangrado) de 0.125″.

Práctica · ficha técnica

03

Dimensiones

Image Size y Canvas Size no son lo mismo.

Tema 3 · Dimensiones

Image Size frente a Canvas Size

Image Size · Alt + Ctrl + I

  • Cambia el tamaño de toda la imagen.
  • Con Resample marcado, cambian los píxeles.
  • Constrain Proportions evita deformar.
  • Reducir: Bicubic Sharper. Ampliar: Bicubic Smoother.
  • Reducir sí; agrandar no.

Canvas Size · Alt + Ctrl + C

  • Cambia el lienzo: añade o quita espacio alrededor.
  • La foto no cambia de tamaño.
  • Anchor: desde dónde crece el lienzo.
  • Relative: suma píxeles a cada lado.
  • Útil para marcos o para dejar espacio al texto.
